# Mayorista Demo · Sistema VB

Demo de evaluación de **Vincular Business** para **mayoristas que venden sólo a comercios**, con datos de ejemplo. Cada venta es mayorista (precio por unidad y por presentación: display, fardo, pallet) y necesita un cliente con CUIT; no hay canal minorista ni consumidor final. Se compila desde el repositorio AlmacenRAVE (`fuente/build.py kini` con `DEMO_ID=vb-demo-mayorista`).
